# Local AI Agent Prompting Guide

How to use **Claude Code**, **Google Antigravity IDE**, **Cursor**, and **OpenAI Codex** to build videos in Creatorize Remotion Studio.

---

## 🤖 Why Local Coding AI Beats Cloud Video Generators

Traditional generative AI video (Runway, Kling, Sora):
- High cost per second of video.
- Inability to edit specific visual elements (e.g. "move the server rack 10px left").
- Text hallucination and blurry artifacts.

**Local AI Coding Assistant + Remotion**:
- Zero cloud render costs — code runs on your local GPU/CPU.
- 100% Deterministic: Exact text spelling, exact colors, exact 3D models.
- Microsecond timing synchronization with spoken words.
- Unlimited revisions: Just ask the AI to change the rotation speed or color palette.

---

## 🛠️ Step-by-Step Prompting Workflow

### 1. In Creatorize Studio:
1. Load your audio and timelined transcript.
2. Select the scene you want to build (e.g. Scene 2: "1998 Silicon Valley Server Boom").
3. Click **"Copy AI Prompt"**.

### 2. In Your AI Assistant (Antigravity / Claude Code / Cursor):
Paste the prompt into your agent. Example prompt generated by the studio:

```text
Please implement the Remotion scene component in `app/src/remotion/scenes/Scene2_SiliconValley.jsx`.

### Constraints:
- Start Frame: 180
- End Frame: 450
- Duration in Frames: 270 frames (9.0 seconds at 30fps)
- Narration: "By 1998, server rooms across Silicon Valley were overheating under unprecedented traffic."
- Style: 3D Isometric Server Room with retro CRT terminal effects.

### Remotion Rules:
1. Use `useCurrentFrame()` and `interpolate()` or `spring()`.
2. Do NOT use CSS transitions or setTimeout.
3. The component must accept `{ durationInFrames, words }` as props.
4. Animate camera rotation smoothly across the 270 frames.
```

### 3. Verification & Live Preview:
Save the file. Because Vite uses Hot Module Replacement, the canvas preview in Creatorize Remotion Studio will instantly reload and display the new scene in motion.
